# Plan — Generation Quality & Moderation (2026-08-01)

Worktree: `cb-generation-quality` · Branch: `worktree-cb-generation-quality`

## Framing

Control what goes **into** the sentence engine (word-class taxonomy) and what comes **out**
(cache curation). One worktree, staged as **3 PRs** for reviewable diffs. Pre-launch content
(site + deck) is tracked separately, not in this worktree.

Load-bearing facts (verified against `main` 2026-08-01):

- **`VocabularyClasses.isCaregiverSelectable` *is* the AI's class menu** — every generation prompt
  injects `caregiverSelectable.map(\.name)`. Editing that array is the single lever for what the AI
  can pick.
- **`wordClass` is injected into the sentence prompt** — `SentencePromptBuilder.swift:63` renders
  `"\(value) (\(wordClass))"`. Taxonomy quality = LLM signal quality. The file header of
  `VocabularyClasses.swift` already states this principle.
- **Pack/starter tags trace to `tools/build_vocab_packs.py` / `build_starter_scenes.py`** (JSON is
  generated). Retag at the Python source, regenerate JSON.
- **`CacheKeyPolicy.key` already folds word class** into the key (its doc-comment uses
  `pony object→animal` as the reclassification example). A taxonomy change is a semantic change →
  bump `promptVersion` to sweep all stale entries at once.
- **`SentenceCache` already has `isPinned` + `tileKeys`.** `evictStale` and `pruneStaleVersions`
  both already exempt `isPinned`. But pinned entries are stored under the **versioned** `cacheKey`,
  so after a `promptVersion` bump a new lookup misses them (remembered-but-unreachable). The durable
  override (`stableKey`) in PR3 fixes that.

## PR 1 — Taxonomy cleanup (do first; touches base vocab)

**Food collapse → `food` + `drinks` only.**
- Retag `fruit`, `veggie`, `snacks`, `meals` → `food` across `vocabulary.json` + packs (+ the
  `tools/build_*.py` sources).
- Remove those four `VocabularyClass` entries from `VocabularyClasses.all`. **Must** retag the data
  in the same PR, or tiles fall back to gray + drop off the AI menu.
- Category/nav tiles (`fruit`, `veggie`, `meals` keys) stay as tiles, reclassed to `food`.
- Accepted cost (deliberate): CollectionSource loses `veggie`/`fruit` as class-query axes for
  one-tap page building. The LLM is the customer, not the collection filter.

**Add `plant` class** — `isCaregiverSelectable: true`, distinct leaf-green
(`Color(red: 0.5, green: 0.62, blue: 0.28)`). Homes flora like `seaweed`, `hay`.

**Tighten `object` (keep, don't remove).**
- Retag mis-tags at the Python source + regenerate: `crab` object→`animal`, `seaweed`/`hay`→`plant`,
  audit `bus` (base vocab's lone `object`)→`places`.
- Rewrite the object rule in the duplicated prompt-guidance blocks (`SceneGeneratorService`,
  `SceneRefinerService`, `TileSuggestionService`, `PageGeneratorService`): *object = man-made
  tools/equipment/vehicles with no better class; prefer animal/plant/places/toy/people first.*
- Factor that guidance into one shared string (candidate: `VocabularyClasses.promptGuidance`) so the
  four copies can't drift.

**Sweep cache:** bump `CacheKeyPolicy.promptVersion` so entries regenerate under new meanings.

**Tests:** class-count assertions; every tile's `wordClass ∈ all` (no orphaned classes → gray);
pack-builder round-trip.

## PR 2 — Cache moderation backend + LLM word audit

**Purge-by API** on `SentenceCacheManager`:
- `invalidate(containingTileKey:)` — filter `tileKeys`.
- `invalidate(wordClass:)` — parse the `key:class` pairs in `cacheKey`.
- **Unconditional — purges even pinned/durable** (safety pull beats caregiver intent).

**Vocab hide/retire:** additive `TileModel.isRetired` flag (reversible; never hard-delete — preserves
CloudKit sync + `LoggedUtterance` history). Hard delete stays an explicit destructive admin path.
Wire retirement → purge (closes the hide→un-hide resurrection gap).

**LLM word-admission moderation audit** (replaces the static-blocklist-as-primary idea) at the
`SceneBuilder.materializeNewWords` choke point, run **before** art-gen:
- **Primary gate = OpenAI `/v1/moderations`** (`omni-moderation-latest`) — free, ~100–300ms, batch
  all new words in one call. Runs synchronously with a spinner; art-gen (DALL-E, seconds) dwarfs it.
- **Two tiers:**
  - *Hard-block* (policy violation) → never sent to image-gen; word rejected with reason. Protects
    the OpenAI account.
  - *Soft-flag* (not a violation but off for a young AAC board, e.g. `beer`/`gun`) → **surface to the
    caregiver — review / keep / remove.** Don't silently censor. A light gpt-4o-mini rubric call
    covers this tier if moderation categories miss it.
- **Static blocklist demoted to a local offline backstop** for a few unambiguous slurs (defense in
  depth), not the primary defense. Composes with the retirement blocklist.

**Correctness gate:** confirmed `pruneStaleVersions`/`evictStale` exempt `isPinned` — keep that;
PR3's durable entries rely on it.

Policy stack established: **safety-purge > durable override > pinned-accepted > versioned cache > TTL.**

## PR 3 — Sentence curation UI (output-side moderation)

Long-press a **tray chip** or **history entry** → menu: **Refine/Try-again · Suppress · Hand-type.**
(Expect some **tray-history work** to surface here — scope when we reach it.)

Durability model (`stableKey` = sorted `tileKeys` + `childID`; no model/prompt/grade/class):

| Action | Lifecycle |
|---|---|
| Plain AI (child tapped tiles) | versioned cache; **evicts** on version bump → regenerates. |
| **Refine / try-again (accepted)** | pinned + `caregiverAccepted`; **TTL-immune**, stays pinned; repeated refinements reaffirm the same pin. On the next version bump, `pruneStaleVersions` **promotes** it (re-key to `stableKey`) instead of skipping — earns permanence when the system would otherwise strand it. |
| **Hand-type** | straight to durable `stableKey` override — explicit intent. |
| **Suppress** | durable `stableKey` override. |

New `SentenceCache` fields (all additive/CloudKit-safe): `stableKey`, `isSuppressed`,
`isCaregiverEdited`, `caregiverAccepted`. Lookup order: **durable override (stableKey) → versioned AI
cache (cacheKey) → generate.** Safety-purge-by-word still reaches durable entries via `tileKeys`.
